# Code-change-v1 reconstruction contract

Snapshot bytes are the product poller's serialized issue_number/title/body payload, not a raw HTTP response. Collection addresses a specific immutable full Git object. W2 accepts the offline profile with model "none", zero calls, zero cost in micro-USD, zero fix generations and the fixed check argv ["git","diff","--check"]. An explicit owner chooses this profile by authorizing the exact task digest for the exact admission and selected pack. Paths are literal repository-relative files. New executable or paid profiles require a new decision. A result records the review of the collected head. It conveys no publication permission.

Fresh W2 sidecars on a scoped v4 store hold the task receipt, producer reservation and producer events. They are initialized on explicit task authorization, without changing the W1 receipt or rewriting historical stores on open. No automatic watch launch. Only the owner's original live grant and current service fence can create fresh work. Collection carries the original task and producer identity through review and approval. W1 local-commit reviews retain their original selector authority. Retries of a terminal operation cannot manufacture a second artifact, event or approval.
